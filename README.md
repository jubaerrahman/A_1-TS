# TypeScript Assignment

## Assignment Overview

This repository contains my assignment on **Problem Solving with TypeScript and Object-Oriented Programming (OOP)**.

The assignment covers different TypeScript concepts, including:

- Basic types and optional parameters
- Union types and type narrowing
- Readonly tuples
- Generics and rest parameters
- Interfaces
- Object-Oriented Programming (OOP)
- Classes, inheritance and access modifiers
- Promises and asynchronous programming
